## 📖 What is GOGX?

**GOGX** is a minimalist userscript designed for Violentmonkey/Tampermonkey that enhances your browsing experience on GOG.com. 

It injects a native-looking purple button on any GOG game page, providing a **direct deep link** to that exact game on a known external GOG game repository (gog-games.to), making searching obsolete.

## ✨ Key Features

* 🚀 **Turbo Injection:** Powered by `MutationObserver`, the button appears instantly, even before GOG's own price section finishes loading.
* 🎯 **Deep Linking:** It doesn't just search; it generates the exact URL to the game's download page, skipping the search results page.
* 🎨 **Native Integration:** Meticulously designed to match GOG.com's UI style, but with a distinct purple hue for easy identification.
* 🛡️ **Safe & Transparent:** No analytics, no tracking, no obfuscated code. Just raw, open-source automation.

## 🛠️ Installation

### Prerequisites
You need a userscript manager installed in your browser. We recommend:
* [Violentmonkey](https://violentmonkey.github.io/) (Recommended)
* [Tampermonkey](https://www.tampermonkey.net/)

### Steps
1.  **[Click here to install GOGX via GitHub Releases](https://github.com/Spicywonda/GOGX-Userscript/raw/refs/heads/main/GOGX.user.js)**
2.  Your userscript manager will open a window. Click **Install**.
3.  Go to GOG.com and visit any game page.
